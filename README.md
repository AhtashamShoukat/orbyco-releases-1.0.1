# Orbyco Desktop Application — Version 1.0.1
We are excited to announce the first official release of **Orbyco Desktop Application**.

## What's Included

- Windows desktop installer
- macOS installer for Apple Silicon (ARM64)
- macOS installer for Intel (x64)
- Initial production release of Orbyco
## Supported Platforms

- Windows 10/11
- macOS — Apple Silicon
- macOS — Intel

## Installation

Download the appropriate installer for your operating system from the assets below and follow the installation instructions.

### Download Options

- **Windows:** `orbyco-Setup-1.0.1.exe`
- **macOS Apple Silicon:** `orbyco-1.0.1-mac-arm64.dmg`
- **macOS Intel:** `orbyco-1.0.1-mac-x64.dmg`
